# مختبر العواصف (Storm Lab)

محاكي رادار طقس للمملكة العربية السعودية.

- `game.html`: اللعبة كاملة في ملف واحد يعمل بدون إنترنت.
- `version.json`: رقم آخر نسخة، ويقرؤه برنامج الكمبيوتر عند التشغيل ليحدّث نفسه تلقائياً.
